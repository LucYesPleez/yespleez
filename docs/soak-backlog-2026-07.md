# Soak / Polish Backlog — post-M5.1, pre-M6

**Status:** ACTIVE. The identity migration is paused at M5.1 (2026-07-12); M6 does not begin until explicitly resumed. This document is the single prioritized backlog for the soak period: real-user testing across every profile type, with each reported issue investigated fresh and classified before any action.

**Triage taxonomy** (assigned after investigation, never assumed):
1. **BUG** — genuine defect
2. **POLISH** — UX/polish improvement
3. **DEBT** — technical debt
4. **REGRESSION** — traced to M5/M5.1 specifically
5. **M6-BLOCKER** — blocks the write cutover or risks data integrity → the only class eligible for immediate fixing during soak
6. **SECURITY** — a live defect in production authorization (RLS/grants). **Added 2026-07-17.** Not an enhancement, not an M6 dependency: it is remediated **on its own schedule, independent of the migration**. The pause does not apply to it, and neither does "wait for M6" — M6 is not its fix.

**Action rule:** M6-BLOCKER and data-integrity items get fixed immediately (investigated → atomic fix → verified → isolated commit). **SECURITY items are scheduled on their own, independent of the migration's state.** Everything else is logged here and waits.

**Brand passes require owner visual verification before they count as done.** Every industry dashboard and profile editor sits behind auth, and behind *being* that profile type — so an assistant can prove a token resolves, that a build passes, and that a change is a visual no-op, but **cannot see the screen**. Those are not the same claim. A brand pass is not complete until a human logs in as that profile type and looks at it. Each pass must therefore end with an explicit **"Manual verification required"** list naming the exact screens and what to look for. Treat an unverified pass as in-progress, not shipped.

**Testing-environment note:** the dev servers serve HEAD **plus the uncommitted feature work** (enquiry flow UI, DJ/PROMOTER rebrand, profile-form refactor, dashboard polish across ~20 files). An issue seen while browsing may live in the uncommitted layer, not in HEAD — classification must say which.
